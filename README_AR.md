# لمّة شات — نسخة Android

هذا المشروع يحتوي على نسخة تجريبية من لمّة شات داخل WebView.

## استخراج APK تلقائيًا
1. ارفع مجلد `LommaChat-Android` إلى مستودع GitHub جديد.
2. افتح تبويب **Actions**.
3. اختر **Build Lomma Chat APK** ثم **Run workflow**.
4. بعد انتهاء البناء افتح نتيجة التشغيل وحمّل ملف `LommaChat-debug-apk`.
5. فك الضغط وثبّت `app-debug.apk` على هاتف Android.

> النسخة الحالية تجريبية ومحلية. لكي يتواصل هاتفان فعليًا عبر الإنترنت نحتاج إضافة خادم وقاعدة بيانات ومصادقة.
